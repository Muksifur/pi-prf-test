Pi Argon2id benchmark

Times Argon2id at several MEMLIMIT/OPSLIMIT settings using the same libsodium.js sumo build as the PWA. Runs each config twice and reports the median. A config is marked CRASH if the run throws or never returns. Run on iPhone Safari and Mac Safari, then send back the result JSON.
