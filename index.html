Project Pi v3 - Passkey PRF Consistency Test

Tests whether the WebAuthn prf extension returns output on this device, and whether the same passkey + same salt produces the same fingerprint everywhere. Register ONCE on iPhone Safari (iCloud Keychain syncs the passkey), then run the authenticate step on every device. Never displays the raw PRF output, only SHA-256 fingerprints.

Step A: Register passkey (iPhone Safari only, once)

Step B: Authenticate with synced passkey (every device/browser)

Mac Chrome: first try the passkey it offers you directly (iCloud Keychain path). If it cannot find one, choose "Use a phone or tablet" and scan the QR with the iPhone. The test records which path was used.
